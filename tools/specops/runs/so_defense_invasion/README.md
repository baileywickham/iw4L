the street, then `autoaim on fire vehicles hunt 5` (soldiers first, `weapnext` to the RPG for BTRs/helis), `give ammo`
every 15 s. Completes in ~10 min (Air 10:08.75): `air.sh so_defense_invasion run.cmds di 1200`.
