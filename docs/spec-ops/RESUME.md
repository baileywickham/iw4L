It rsyncs the worktree (not `context/`), builds there, takes an atomic lock so runs queue, runs with `IW4L_AIR_TIMEOUT` (default 300 s), and copies `latest.log` + screenshots back to `<worktree>/iw4l-artifacts/air/`. - Air setup: AC pmset `displaysleep 0 sleep 0`, screensaver off, `caffeinate -dis`, lid open, unlocked. A locked/occluded window gets no frames and the world-spawn GPU gate waits forever (`window surface: no frame to draw`).

## Run scripts

`tools/specops/` holds the scripted runs (copy to `context/` — some scripts assume `context/runs/...` and contain absolute paths for this Mac):

```
cp -r tools/specops/runs tools/specops/pit_runs tools/specops/coop context/
```

- `runs/<mission>/run.cmds` per mission (+ `gen.py` where generated), `runs/README.md`, `runs/air.sh <map> <cmds> <logname> [timeout] [K=V…]`, `runs/regress.sh`, `runs/ents.py` (dumps a zone's entities — regenerate locally; extracted data is not committed).
- **Command files have one command group per line: join with `;` and drop `#` comments** (`grep -v '^#' f | grep -v '^[[:space:]]*$' | paste -sd';' -`). Joining with spaces silently swallows commands.
- The Pit: `pit_runs/pit_run.cmds` (generated by `pit_run.py`), `pit_runs/README.md`.

Typical run: `IW4L_AIR_TIMEOUT=600 ~/bin/iw4l-air "$PWD" --env IW4L_GSC_STUB_NATIVES=1 -- map so_killspree_favela --cmds "$(grep -v '^#' context/runs/so_killspree_favela/run.cmds | grep -v '^[[:space:]]*$' | paste -sd';' -)"`.

## Dev env flags

| flag | what |
|---|---|
| `IW4L_GSC_STUB_NATIVES=1` | unbound natives/unknown builtins become logged stubs (all SO runs use it) |
| `IW4L_GSC_USAGE=1` | histogram of stub calls, runtime errors, actor field use at quit |
| `IW4L_GSC_STATS=1`, `IW4L_GSC_HITCH_MS`, `IW4L_SIM_STATS=1` | script/sim timing census, breakdown of slow ticks |
| `IW4L_GSC_TRACE_LEVEL=1`, `IW4L_GSC_TRACE_NOTIFY=a,b` | log level notifies / chosen notifies |
| `IW4L_SCRIPT_OVERRIDE=<dir>` | loose `.gsc` files override zone scripts |
| `IW4L_AUTOAIM=1` | test aimer: while `+attack` is held, turns to the nearest visible enemy (`=3` hunts) |
| `IW4L_AUTOFIRE=1` (`_RANGE`) | test aimer that aims and fires on its own |
| console `autoaim on [fire] [vehicles] [hunt <s>]`, `enemies` | dev aim helper / list hostiles (cheats on) |
| `IW4L_VEH_AUTODRIVE=1` | snowmobile autopilot (`=2` logs decisions) |
| `IW4L_TRIGGER_LOG=1` | named trigger bounds/hull centres (teleport targets) |
| `IW4L_AI_ACCURACY_LOG=1`, `IW4L_ACTOR_MOTION_LOG=1`, `IW4L_ANIM_NOTE_LOG=1`, `IW4L_ANIMTREE_MISSING=1`, `IW4L_HELI_LOG=1` | subsystem logs |
| `IW4L_WINDOW_ON_TOP=1`, `IW4L_WINDOW_POS=x,y` | keep the window presented / place it |
| `IW4L_PIPELINED_RENDERING=0`, `IW4L_FRAME_LATENCY` | render pipelining (on by default on macOS now) |
| `IW4L_PROFILE_PATH` | isolate the profile (stars) file |
| `IW4L_FRAME_DUMP=<dir>[,fps]` (+ `_FROM`, `_WIDTH`, `_MAX`, `_SKIP_MS`, `_NO_PNG`) | vibe check: fixed-step demo replay, every frame to PNG + per-entity presentation metrics; `tools/specops/vibe/` (`capture.sh`, `vibe.py`, `REVIEW.md`) |
